# 💀 Властелин Указателей | Low-Level & Bare Metal Developer

> "Если язык делает всю работу с памятью за тебя — ты не программист, ты просто корм для нейросетей."

Привет. Я пишу код, который общается с железом напрямую, а не через десять слоев абстракций и интерпретаторов. В мире, где разработчики соревнуются в знании модных фреймворков и молятся на сборщик мусора, я спускаюсь туда, где живут биты, регистры процессора и сырая память. 

Для меня не существует разницы между операционными системами. Windows, macOS, Linux, UEFI или голый микроконтроллер — всё это лишь песочницы. Настоящая работа идет под капотом.

### 🔪 Что я творю:
* Пишу код, который играет в русскую рулетку с битами в памяти до полного краша системы ради искусства и экспериментов.
* Работаю с физическими адресами и регистрами без оглядки на API операционных систем.
* Выжимаю каждый такт из CPU и доказываю, что ручное управление памятью — это единственный путь к абсолютному контролю.
* Создаю перформансы на стыке низкоуровневого программирования и безумия.

### ⚙️ Мой арсенал:
* **Языки:** C, C++, Rust (и никакого спасительного Garbage Collector'а).
* **Скиллы:** Ручное выделение памяти, побитовые операции, работа с указателями, дизассемблирование, понимание архитектуры (x86/ARM).
* **Философия:** Если программа не может вызвать `Triple Fault` или повесить железо намертво — ей не хватает привилегий.
